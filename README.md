# 🚀 Personal Portfolio & Content Operations Showcase

Welcome to the source code for my personal portfolio website! 

This website serves as an interactive showcase of my work as a **Content Growth Operator**, featuring my video editing projects, published articles/newsletters, and analytical approaches to audience retention and distribution.

---

## 📌 Features

- **🎬 Video Editing Portfolio:** Highlighting short-form (Shorts/Reels) and long-form video edits with retention-focused pacing and color grading.
- **✍️ Writing & Publication Samples:** Selected essays, diary excerpts, and newsletter post layouts (Substack format).
- **📊 Analytics & Strategy Showcase:** Sample content audits, viewer retention breakdown models, and distribution workflows.
- **📱 Responsive & Clean UI:** Fast-loading, minimalistic design optimized for desktop and mobile viewing.

---

## 🛠️ Tech Stack & Tools

### **Development & Deployment**
- **Frontend:** HTML5, CSS3, JavaScript
- **Hosting / Deployment:** GitHub Pages / Vercel / Netlify

### **Creative & Analytics Tools Represented**
- **Video Post-Production:** CapCut, shotcut, 
- **Publishing & Growth:** Substack, YouTube Studio, Social Media Analytics
